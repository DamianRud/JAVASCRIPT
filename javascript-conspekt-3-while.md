# JavaScript — Конспект №3

## Цикл `while`

### Что такое `while`?

`while` — это цикл, который повторяет код до тех пор, пока условие истинно (`true`).

### Синтаксис

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

Результат:

```text
1
2
3
4
5
```

### Как работает `while`

**1. Создаём переменную**

```javascript
let i = 1;
```

Это начальное значение.

**2. Проверяем условие**

```javascript
while (i <= 5)
```

Пока условие истинно (`true`), цикл продолжает работать.

**3. Выполняем код**

```javascript
console.log(i);
```

Выводим значение.

**4. Изменяем переменную**

```javascript
i++;
```

После каждого круга увеличиваем значение на 1.

### Пример

```javascript
let i = 3;

while (i <= 6) {
    console.log(i);
    i++;
}
```

Результат:

```text
3
4
5
6
```

### Обратный цикл

Можно считать в обратную сторону.

```javascript
let i = 5;

while (i >= 1) {
    console.log(i);
    i--;
}
```

Результат:

```text
5
4
3
2
1
```

### Самая частая ошибка

Если забыть изменить переменную:

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
}
```

Получится:

```text
1
1
1
1
1
...
```

Цикл никогда не закончится.
Это называется **бесконечный цикл** (Infinite Loop).

### Отличие `for` и `while`

**`for`**

Используется, когда известно, сколько раз нужно повторить код.

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

**`while`**

Используется, когда повторение зависит только от условия.

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

### Что важно запомнить

**Обычный цикл**

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

**Обратный цикл**

```javascript
let i = 10;

while (i >= 1) {
    console.log(i);
    i--;
}
```

**Не забывать изменять переменную**

```javascript
i++;
```

или

```javascript
i--;
```

Иначе получится бесконечный цикл.

## Моя шпаргалка

- `for` → когда известно количество повторений.
- `while` → пока условие истинно.
- `i++` → увеличить на 1.
- `i--` → уменьшить на 1.
- Не забывай изменять переменную внутри `while`, иначе получится бесконечный цикл.
