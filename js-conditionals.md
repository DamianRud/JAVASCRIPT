# Условные операторы в JavaScript (`if / else`)

## 📌 Зачем нужны?

Условные операторы позволяют программе **принимать решения** и выполнять разный код в зависимости от заданных условий.

---

## 1. Базовая конструкция `if / else`

Срабатывает первый блок, условие которого истинно (`true`). Если все условия ложны — выполняется блок `else`.

```js
let age = 16;

if (age >= 18) {
  console.log("Доступ разрешен");
} else {
  console.log("Доступ ограничен");
}
```

---

## 2. Несколько вариантов — `else if`

Используется, когда нужно проверить **больше двух** вариантов. Проверки идут по порядку сверху вниз, срабатывает первая истинная.

```js
let score = 75;

if (score >= 90) {
  console.log("Отлично");
} else if (score >= 70) {
  console.log("Хорошо");
} else {
  console.log("Удовлетворительно или ниже");
}
```

---

## 3. Логические операторы

Помогают объединять несколько условий в одной проверке:

| Оператор | Название | Работает так |
|----------|----------|--------------|
| `&&` | И (AND) | `true`, только если **оба** условия верны |
| `\|\|` | ИЛИ (OR) | `true`, если хотя бы **одно** условие верно |
| `!` | НЕ (NOT) | инвертирует значение (`true` → `false` и наоборот) |

**Пример `&&`** — проверка диапазона:

```js
let hour = 9;

if (hour >= 6 && hour <= 11) {
  console.log("Доброе утро!");
}
```

---

## 4. Вложенные условия

Условие можно поместить внутрь другого условия, если нужна дополнительная проверка.

```js
let score = 95;
let hasAttendedClasses = true;

if (score >= 90) {
  if (hasAttendedClasses === true) {
    console.log("Повышенная стипендия!");
  } else {
    console.log("Без стипендии.");
  }
}
```

**Пример:** проверить посещаемость только при достаточном количестве баллов.

---

## 🧠 Кратко

- `if / else` — выбор из двух вариантов
- `else if` — выбор из нескольких вариантов
- `&&`, `||`, `!` — объединение и инверсия условий
- Вложенные `if` — дополнительная проверка внутри уже пройденного условия
