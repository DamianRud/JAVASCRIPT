# JavaScript — Массивы (Arrays)

## Что такое массив?

Массив хранит несколько значений в одной переменной.

### Пример

```javascript
let fruits = ["Яблоко", "Банан", "Арбуз"];
```

---

## Индексы массива

Каждый элемент имеет свой номер.

```text
0 → Яблоко
1 → Банан
2 → Арбуз
```

Получить элемент можно так:

```javascript
console.log(fruits[0]);
```

Ответ:

```text
Яблоко
```

---

## length

Показывает количество элементов.

```javascript
let fruits = ["Яблоко", "Банан", "Арбуз"];

console.log(fruits.length);
```

Ответ:

```text
3
```

---

## push()

Добавляет элемент в конец массива.

```javascript
let fruits = ["Яблоко"];

fruits.push("Банан");
```

Получится:

```text
["Яблоко", "Банан"]
```

---

## pop()

Удаляет последний элемент.

```javascript
let fruits = ["Яблоко", "Банан"];

fruits.pop();
```

Получится:

```text
["Яблоко"]
```

---

## unshift()

Добавляет элемент в начало.

```javascript
let fruits = ["Банан"];

fruits.unshift("Яблоко");
```

Получится:

```text
["Яблоко", "Банан"]
```

---

## shift()

Удаляет первый элемент.

```javascript
let fruits = ["Яблоко", "Банан"];

fruits.shift();
```

Получится:

```text
["Банан"]
```

---

## Цикл for + массив

### Зачем нужен?

Позволяет пройти по всем элементам массива.

### Пример

```javascript
let games = ["CS2", "Minecraft", "GTA V"];

for (let i = 0; i < games.length; i++) {
    console.log(games[i]);
}
```

Ответ:

```text
CS2
Minecraft
GTA V
```

---

### Почему i = 0?

Потому что индексы массива начинаются с нуля.

```text
0
1
2
```

---

### Почему i < games.length?

Если написать:

```javascript
i <= games.length
```

то программа попытается получить элемент:

```javascript
games[3]
```

которого не существует.

Получится:

```text
undefined
```

---

## Шпаргалка

```text
push()      → добавить в конец

pop()       → удалить с конца

unshift()   → добавить в начало

shift()     → удалить с начала

length      → количество элементов

array[i]    → получить элемент

for         → пройти по массиву
```
